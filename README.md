## 📁 Project Structure

```
Portfolio/
├── public/                 # Static assets & profile picture
├── src/
│   ├── components/         # Reusable UI components (Navbar, Footer, ContactForm, etc.)
│   ├── contexts/           # LanguageContext (TR / EN i18n support)
│   ├── data/               # Profile, projects, and career data (profile.ts)
│   ├── pages/              # Home, About, Skills, Projects, Experience, Contact, NotFound
│   ├── App.tsx             # Application routes & provider setup
│   ├── index.css           # Global stylesheet & Tailwind directives
│   └── main.tsx            # React application entry point
├── .github/workflows/      # Automated deployment to GitHub Pages
├── package.json
└── vite.config.ts
```

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/MertP06/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build for production:
```bash
npm run build
```
